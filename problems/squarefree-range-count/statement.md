# 区间无平方因子数计数

如果一个正整数 $x$ 满足 **不存在素数 $p$ 使得 $p^2$ 整除 $x$**，则称 $x$ 为「无平方因子数」（square-free number）。换句话说，$x$ 的每个素因子的幂次都不超过 1。注意 $1$ 没有素因子，因此它是无平方因子数。

例如：
- $1, 2, 3, 5, 6, 7$ 是无平方因子数。
- $4 = 2^2$（$2^2 \mid 4$）、$8 = 2^3$（$2^2 \mid 8$）、$9 = 3^2$、$12 = 2^2 \times 3$（$2^2 \mid 12$）都不是无平方因子数。

给定两个正整数 `left` 和 `right`，返回闭区间 `[left, right]` 中无平方因子数的个数。

## 示例

### 示例 1

输入：1, 10  
输出：7  
解释：区间 [1, 10] 内的数逐一判断：  

| 数 | 是否无平方因子 | 原因 |
|---|---|---|
| 1 | 是 | 无素因子 |
| 2 | 是 | 素因子仅为 2，幂次 1 |
| 3 | 是 | 素因子仅为 3，幂次 1 |
| 4 | 否 | $2^2 = 4 \mid 4$ |
| 5 | 是 | 素因子仅为 5，幂次 1 |
| 6 | 是 | $6 = 2 \times 3$，素因子幂次均为 1 |
| 7 | 是 | 素因子仅为 7，幂次 1 |
| 8 | 否 | $2^2 = 4 \mid 8$ |
| 9 | 否 | $3^2 = 9 \mid 9$ |
| 10 | 是 | $10 = 2 \times 5$，素因子幂次均为 1 |

共 7 个。

### 示例 2

输入：1, 20  
输出：13  
解释：区间 [1, 20] 中非无平方因子数为 {4, 8, 9, 12, 16, 18, 20}，共 7 个。其中 4、8、12、16、20 均可被 $2^2$ 整除，9、18 可被 $3^2$ 整除；其余 13 个数均无法被任何素数的平方整除，故答案为 $20 - 7 = 13$。  

### 示例 3

输入：4, 4  
输出：0  
解释：区间仅含 4，$2^2 = 4 \mid 4$，不是无平方因子数，结果为 0。  

## 约束

- $1 \le \text{left} \le \text{right} \le 10^6$
