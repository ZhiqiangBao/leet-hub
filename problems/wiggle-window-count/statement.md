# 交替窗口计数

## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`。

长度为 `k` 的连续子数组称为 **交替窗口**，当且仅当它满足以下条件：

1. 任意相邻的两个元素不相等；
2. 任意相邻两段的大小关系严格交替：若 `nums[i] < nums[i+1]` 表示上升段，`nums[i] > nums[i+1]` 表示下降段，则整个窗口内的上升/下降必须交替出现。

> 特别说明：当 `k == 1` 时，窗口内不存在相邻元素对，规定所有长度为 1 的子数组均为交替窗口。

请你返回数组中交替窗口的总数。

## 示例

**示例 1**

```
输入：nums = [1, 2, 3, 4, 5], k = 3
输出：0
解释：所有长度为 3 的子数组均为单调递增，相邻段大小关系符号相同，没有任何窗口满足交替条件。
```

**示例 2**

```
输入：nums = [1, 2, 2, 4, 5], k = 2
输出：3
解释：共 4 个长度为 2 的窗口，其中 [1,2]、[2,4]、[4,5] 均满足条件（各段为上升），而 [2,2] 因相邻元素相等不满足。共 3 个交替窗口。
```

**示例 3**

```
输入：nums = [1, 3, 2, 4, 1, 3], k = 3
输出：4
解释：共 4 个长度为 3 的窗口，逐一检验：
- [1, 3, 2]：1↗3↘2，一升一降，满足条件。
- [3, 2, 4]：3↘2↗4，一降一升，满足条件。
- [2, 4, 1]：2↗4↘1，一升一降，满足条件。
- [4, 1, 3]：4↘1↗3，一降一升，满足条件。
  4 个窗口全部满足交替条件。
```

## 约束

- `1 <= k <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
