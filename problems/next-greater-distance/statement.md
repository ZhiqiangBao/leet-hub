# 下一个更大元素的最远跳距

给你一个整数数组 `nums`。对于每个下标 `i`，在它的右边（下标大于 `i`）找到**第一个**严格大于 `nums[i]` 的元素所在的下标 `j`（即满足 `nums[j] > nums[i]` 且对所有满足 `i < k < j` 的 `k` 都有 `nums[k] ≤ nums[i]`）。定义跳距 `d_i = j − i`；如果右边不存在这样的元素，则 `d_i = 0`。

返回所有跳距中的最大值。

## 示例 1

输入：nums = [1, 5, 3, 2, 4]
输出：2
解释：i=0 时第一个右侧更大元素在下标 1（值 5），跳距 1；i=1 时无右侧更大元素，跳距 0；i=2 时第一个右侧更大元素在下标 4（值 4），跳距 2；i=3 时第一个右侧更大元素在下标 4（值 4），跳距 1；i=4 时无右侧更大元素，跳距 0。最大值为 2。

## 示例 2

输入：nums = [3, 3, 2, 5, 1]
输出：3
解释：i=0 时第一个右侧更大元素在下标 3（值 5），跳距 3；i=1 时第一个右侧更大元素在下标 3（值 5），跳距 2；i=2 时第一个右侧更大元素在下标 3（值 5），跳距 1；i=3 时无右侧更大元素，跳距 0；i=4 时无右侧更大元素，跳距 0。最大值为 3。

## 示例 3

输入：nums = [2, 1, 1, 1, 6]
输出：4
解释：i=0 时第一个右侧更大元素在下标 4（值 6），跳距 4；i=1 时第一个右侧更大元素在下标 4（值 6），跳距 3；i=2 时第一个右侧更大元素在下标 4（值 6），跳距 2；i=3 时第一个右侧更大元素在下标 4（值 6），跳距 1；i=4 时无右侧更大元素，跳距 0。最大值为 4。

## 约束

- `1 ≤ nums.length ≤ 10^5`
- `1 ≤ nums[i] ≤ 10^9`
- 元素可以重复。「严格大于」指 `nums[j] > nums[i]`，等于不算。
