# K-非相邻子序列最大和

给你一个正整数数组 `nums` 和一个整数 `k`。请你从数组中选出恰好 `k` 个元素，使得任意两个被选元素在原数组中的下标之差的绝对值不小于 `2`（即不能选择相邻位置的元素）。返回所选元素可能的最大和。如果无法选出 `k` 个满足条件的元素，返回 `-1`。

## 示例

### 示例 1

输入：[1, 2, 3, 4, 5], 2  
输出：8  
解释：选中下标 2 与下标 4（值 3 与 5），和为 8。  

### 示例 2

输入：[5, 1, 1, 5], 3  
输出：-1  
解释：数组长度为 4，受限于不能选相邻元素，最多仅能选 2 个下标。因此无法选出 3 个，返回 -1。  

### 示例 3

输入：[2, 7, 9, 3, 1], 2  
输出：11  
解释：选择下标 0 和 2（对应值 2 与 9），下标差为 2 且均合法，和为 11。其他如 (0, 3)、(0, 4) 等组合虽合法但总和更小。  

## 约束

- `1 ≤ nums.length ≤ 500`
- `1 ≤ k ≤ nums.length`
- `1 ≤ nums[i] ≤ 1000000`
