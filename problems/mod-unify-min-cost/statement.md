# 统一余数最少操作次数

题意：给你一个正整数数组 `nums` 和一个正整数 `k`。每次操作可以将数组中的任意一个元素加 1。求使得数组中所有元素对 `k` 取模的余数都相同所需的最少操作次数。

## 示例

### 示例 1

输入：[4, 7, 9], 4  
输出：3  
解释：目标余数取 1。4 需要 1 次操作变为 5（5 mod 4 = 1），7 需要 2 次操作变为 9（9 mod 4 = 1），9 不需要操作（9 mod 4 = 1）。共需 1 + 2 + 0 = 3 次操作。  

### 示例 2

输入：[1, 2, 3, 4], 3  
输出：3  
解释：目标余数取 1。1 不需要操作（1 mod 3 = 1），2 需要 2 次操作变为 4（4 mod 3 = 1），3 需要 1 次操作变为 4（4 mod 3 = 1），4 不需要操作（4 mod 3 = 1）。共需 0 + 2 + 1 + 0 = 3 次操作。  

### 示例 3

输入：[2, 4], 3  
输出：1  
解释：目标余数取 2。2 不需要操作（2 mod 3 = 2），4 需要 1 次操作变为 5（5 mod 3 = 2）。共需 0 + 1 = 1 次操作。  

## 约束

- `n = nums.length`，1 ≤ n ≤ 100000
- 1 ≤ k ≤ 1000
- 1 ≤ nums[i] ≤ 1000000000
