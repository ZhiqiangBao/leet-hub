# 区间中位三元组

给你一个下标从 **0** 开始的整数数组 `nums` 和两个整数 `lo`、`hi`（保证 `lo ≤ hi`）。

先将 `nums` 按升序排序，得到长度为 $n$ 的数组 $b$（$n$ 为 `nums` 的长度）。统计满足以下条件的三元组 $(i, j, k)$ 个数：

- $0 \le i < j < k \le n-1$
- $lo \le b[j] \le hi$

换句话说，从原数组任选三个不同位置的元素，将它们的值放在有序位置后，中间那个值落在 `[lo, hi]` 内的选法有多少种。重复值按排序后的下标区分，不合并；若 $n < 3$，则没有合法的三元组，答案为 $0$。

## 示例

**示例 1：**

输入：[1, 3, 2, 4], 2, 3
输出：4


**解释：** 排序后 $b = [1, 2, 3, 4]$。符合条件的三元组为 $(0,1,2)$ 中位 $b[1]=2\in[2,3]$、$(0,1,3)$ 中位 $b[1]=2\in[2,3]$、$(0,2,3)$ 中位 $b[2]=3\in[2,3]$、$(1,2,3)$ 中位 $b[2]=3\in[2,3]$，共 4 个。

**示例 2：**

输入：[2, 2, 2, 2, 2, 2], 1, 3
输出：20


**解释：** 排序后 $b = [2, 2, 2, 2, 2, 2]$。所有 $b[j]=2$ 都在 $[1,3]$ 内，因此任意三元组的中位均符合条件，共 $\binom{6}{3}=20$ 个。

**示例 3：**

输入：[1, 2, 3], 1, 1
输出：0


**解释：** 排序后 $b = [1, 2, 3]$。只有 $b[0]=1$ 在 $[1,1]$ 内，但 $j=0$时左侧没有可选的下标 $i$，因此不产生任何计入的三元组。其余下标不在区间内。合计 $0$。

## 约束

- $1 \le n \le 1500$
- $-10^9 \le nums[i] \le 10^9$
- $-10^9 \le lo \le hi \le 10^9$
