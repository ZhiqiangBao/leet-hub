# 左右众数不同的分割点

## 题目描述

给定一个长度为 $n$ 的整数数组 `nums`。选择下标 $i$（$0 \le i \le n-2$）从位置 $i$ 之后切开，分为左段 `nums[0..i]` 和右段 `nums[i+1..n-1]`。

每段的**众数**定义为段内出现频率最高的元素。若存在多个元素并列最高频，取其中**数值最小**者作为该段众数。

统计有多少个 $i$ 使得左段众数 $\neq$ 右段众数。返回此数量。

## 示例

### 示例 1

输入：nums = [1, 2, 1, 2]
输出：2
解释：i=0: 左众数1≠右众数2✓; i=1: 1=1✗; i=2: 1≠2✓


逐分割说明：
- $i=0$：左段 $[1]$，众数为 1；右段 $[2,1,2]$，频次 $\{2:2, 1:1\}$，众数为 2。$1 \ne 2$，计入。
- $i=1$：左段 $[1,2]$，频次 $\{1:1, 2:1\}$ 并列，取较小值 1；右段 $[1,2]$ 同理众数也为 1。$1 = 1$，不计入。
- $i=2$：左段 $[1,2,1]$，频次 $\{1:2, 2:1\}$，众数为 1；右段 $[2]$，众数为 2。$1 \ne 2$，计入。

共 2 个。

### 示例 2

输入：nums = [1, 1, 2, 2, 3, 3]
输出：5
解释：全部 5 个分割左右众数均不同。


逐分割说明：
- $i=0$：左段 $[1]$，众数 1；右段 $[1,2,2,3,3]$，$\{1:1, 2:2, 3:2\}$ 最高频 2 并列取小得 2。$1 \ne 2$。
- $i=1$：左段 $[1,1]$，众数 1；右段 $[2,2,3,3]$，$\{2:2, 3:2\}$ 并列取小得 2。$1 \ne 2$。
- $i=2$：左段 $[1,1,2]$，$\{1:2, 2:1\}$，众数 1；右段 $[2,3,3]$，$\{2:1, 3:2\}$，众数 3。$1 \ne 3$。
- $i=3$：左段 $[1,1,2,2]$，$\{1:2, 2:2\}$ 并列取小得 1；右段 $[3,3]$，众数 3。$1 \ne 3$。
- $i=4$：左段 $[1,1,2,2,3]$，$\{1:2, 2:2, 3:1\}$ 最高频 2 并列取小得 1；右段 $[3]$，众数 3。$1 \ne 3$。

共 5 个。

### 示例 3

输入：nums = [7, 7, 7]
输出：0
解释：全部分割左右众数均为 7。


逐分割说明：
- $i=0$：左段 $[7]$，众数 7；右段 $[7,7]$，众数 7。$7 = 7$，不计入。
- $i=1$：左段 $[7,7]$，众数 7；右段 $[7]$，众数 7。$7 = 7$，不计入。

共 0 个。

## 约束

- $2 \le n \le 10^5$
- $1 \le \text{nums}[i] \le 10^9$
