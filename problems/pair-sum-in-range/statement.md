# 范围内元素对之和的个数

给你一个整数数组 `nums` 和两个整数 `lo`、`hi`，满足 `lo ≤ hi`。

统计所有下标对 `(i, j)`（其中 `i < j`）中满足 `lo ≤ nums[i] + nums[j] ≤ hi` 的对数，并返回这个计数。

## 示例

### 示例 1

输入：[1, 4, 6, 7, 12], 5, 10  
输出：4  
解释：枚举所有 `i < j` 的下标对：  

| (i,j) | nums[i]+nums[j] | 是否在 [5,10] |
|-------|-----------------|---------------|
| (0,1) | 1+4 = **5**     | ✅            |
| (0,2) | 1+6 = **7**     | ✅            |
| (0,3) | 1+7 = **8**     | ✅            |
| (0,4) | 1+12 = 13       | ❌            |
| (1,2) | 4+6 = **10**    | ✅            |
| (1,3) | 4+7 = 11        | ❌            |
| (1,4) | 4+12 = 16       | ❌            |
| (2,3) | 6+7 = 13        | ❌            |
| (2,4) | 6+12 = 18       | ❌            |
| (3,4) | 7+12 = 19       | ❌            |

共 **4** 对符合条件。

### 示例 2

输入：[1, 2, 3, 4, 5], 4, 9  
输出：9  
解释：枚举所有 `i < j` 的下标对：  

| (i,j) | nums[i]+nums[j] | 是否在 [4,9] |
|-------|-----------------|--------------|
| (0,1) | 1+2 = **3**     | ❌           |
| (0,2) | 1+3 = **4**     | ✅           |
| (0,3) | 1+4 = **5**     | ✅           |
| (0,4) | 1+5 = **6**     | ✅           |
| (1,2) | 2+3 = **5**     | ✅           |
| (1,3) | 2+4 = **6**     | ✅           |
| (1,4) | 2+5 = **7**     | ✅           |
| (2,3) | 3+4 = **7**     | ✅           |
| (2,4) | 3+5 = **8**     | ✅           |
| (3,4) | 4+5 = **9**     | ✅           |

共 **9** 对符合条件。

### 示例 3

输入：[3, 1], 3, 3  
输出：0  
解释：唯一的下标对 `(0,1)`，`3+1=4`，而 `4 > hi=3`，不在 `[3,3]` 内，故结果为 **0**。  

## 约束

- `2 ≤ nums.length ≤ 10^5`
- `-10^8 ≤ nums[i] ≤ 10^8`
- `-10^8 ≤ lo ≤ hi ≤ 10^8`
- 答案保证落在 32 位有符号整数范围 `[−2^31, 2^31 − 1]` 内。
