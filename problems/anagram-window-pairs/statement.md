# 异序窗口对

## 题目描述

给定一个由小写英文字母组成的字符串 $s$ 和一个正整数 $L$。

对于每个起始位置 $i$（$0 \le i \le |s| - L$），定义**窗口** $w_i$ 为子串 $s[i : i+L]$，即从位置 $i$ 开始、长度为 $L$ 的连续子串。如果 $L > |s|$，则不存在任何窗口。

统计满足以下条件的下标对 $(i, j)$ 的数量：

- $0 \le i < j$，且两个窗口 $w_i$ 和 $w_j$ 均存在；
- $w_i$ 与 $w_j$ **互为异序词**（即两子串包含的每种字符的数量完全相同，只是排列顺序可能不同）。

返回互异序词的窗口对总数。

## 输入格式

函数接收两个参数：

- `s`：只含小写英文字母的字符串，长度 $n = |s|$；
- `L`：正整数。

## 输出格式

返回一个非负整数，表示互为异序词的窗口对数量。

## 约束

- $1 \le n = |s| \le 6\times10^4$
- $1 \le L \le 10^5$
- 若 $L > n$，直接返回 0。
- 答案不超过 $2^{31}-1$。

## 示例

**示例 1**

```
输入：s = "ababa", L = 2
输出：6
解释：四个窗口分别为 "ab"(pos 0)、"ba"(pos 1)、"ab"(pos 2)、"ba"(pos 3)，全部含有 1 个 'a' 和 1 个 'b'，属于同一组异序词，答案为 C(4,2) = 6。
```

**示例 2**

```
输入：s = "aabaaa", L = 3
输出：3
解释：位置 0 的窗口 "aab"、位置 1 的窗口 "aba"、位置 2 的窗口 "baa" 都具有相同的字母计数 {a:2, b:1}，组成一组，产生 3 对；位置 3 的窗口 "aaa" 无同伴。总计 3 对。
```

**示例 3**

```
输入：s = "abc", L = 5
输出：0
解释：L = 5 > n = 3，不存在任何窗口，直接返回 0。
```
