# 双约束最少分组

## 题目描述

给你一个整数数组 `nums` 和一个非负整数 `d` 与一个正整数 `m`。你需要把 `nums` 中的所有元素分配到若干个组中，满足以下两个条件：

1. **值差约束**：每个组内最大值与最小值的差不超过 `d`。
2. **容量约束**：每个组的元素个数不超过 `m`。

请返回满足条件的最少组数。

> **注意**：每个元素必须且只能属于一个组；分组不需要保持原数组的连续关系，只需按元素值划分即可。

## 示例

**示例 1**

```
输入：nums = [1,1,2,2,2,3], d = 0, m = 3
输出：3
解释：d = 0 表示同组元素必须全部相等。最优分组为 {1, 1}、{2, 2, 2}、{3}，共 3 个组。
```

**示例 2**

```
输入：nums = [3,5,1,4], d = 99, m = 1
输出：4
解释：m = 1 表示每组最多只有一个元素，因此必须分为 4 个组。
```

**示例 3**

```
输入：nums = [1,2,4,5,7,8,9], d = 2, m = 2
输出：4
解释：排序后为 [1,2,4,5,7,8,9]。贪心分组：{1, 2}（差 1 ≤ d）、{4, 5}（差 1 ≤ d）、{7, 8}（差 1 ≤ d）、{9}，共 4 个组。
```

## 约束

- $1 \leq \text{nums.length} \leq 10^5$
- $1 \leq m \leq \text{nums.length}$
- $0 \leq d \leq 10^9$
- $0 \leq \text{nums}[i] \leq 10^9$
