# 等 gcd 分割计数

给定一个正整数数组 nums。你可以在下标 1..n-1 之间任选一个位置将数组切成非空的两段：左半为下标 0..i-1，右半为下标 i..n-1。求有多少个切点 i，使得左半所有元素的最大公约数与右半所有元素的最大公约数相等。（数组长度 n = nums.length，下标从 0 开始。）

## 示例

### 示例 1

输入：[2, 3, 6, 4]  
输出：0  
解释：共 3 个切点。i=1 时左半 GCD = 2，右半 GCD = gcd(3, 6, 4) = 1，不等；i=2 时左半 GCD = gcd(2, 3) = 1，右半 GCD = gcd(6, 4) = 2，不等；i=3 时左半 GCD = gcd(2, 3, 6) = 1，右半 GCD = 4，不等。没有相等的切点，答案为 0。  

### 示例 2

输入：[2, 2]  
输出：1  
解释：唯一切点 i=1，左半 GCD = 2，右半 GCD = 2，相等，答案为 1。  

### 示例 3

输入：[4, 8, 12]  
输出：1  
解释：共 2 个切点。i=1 时左半 GCD = 4，右半 GCD = gcd(8, 12) = 4，相等计入；i=2 时左半 GCD = gcd(4, 8) = 4，右半 GCD = 12，不等不计入。答案为 1。  

## 约束

- n = nums.length，2 <= n <= 100000
- 1 <= nums[i] <= 1000000000
