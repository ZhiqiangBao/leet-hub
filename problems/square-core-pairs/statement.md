# 完全平方积对数

给定一个正整数数组 `nums`，统计满足以下条件的下标对 `(i, j)` 的数量：

- `i < j`
- `nums[i] * nums[j]` 是完全平方数（即存在正整数 `t` 使得 `nums[i] * nums[j] = t²`）

值相同但下标不同的元素视为不同元素，按位置计数。

## 示例

### 示例 1

输入：[2, 8, 3, 12, 18]  
输出：4  
解释：下标对与积如下：(0,1)→16=4²，计入；(0,2)→6，不计入；(0,3)→24，不计入；(0,4)→36=6²，计入；(1,2)→24，不计入；(1,3)→96，不计入；(1,4)→144=12²，计入；(2,3)→36=6²，计入；(2,4)→54，不计入；(3,4)→216，不计入。共计 4 对。  

### 示例 2

输入：[1, 4, 9]  
输出：3  
解释：下标对与积如下：(0,1)→4=2²，计入；(0,2)→9=3²，计入；(1,2)→36=6²，计入。全部 3 对均计入。  

### 示例 3

输入：[2, 2, 8, 8]  
输出：6  
解释：下标对与积如下：(0,1)→4=2²，计入；(0,2)→16=4²，计入；(0,3)→16=4²，计入；(1,2)→16=4²，计入；(1,3)→16=4²，计入；(2,3)→64=8²，计入。全部 6 对均计入。  

## 约束

- `n = nums.length`，`1 ≤ n ≤ 100000`
- `1 ≤ nums[i] ≤ 1000000`
