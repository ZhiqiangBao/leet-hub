# 占优下标计数

给定一个整数数组 `nums`，如果下标 `i` 满足 **`nums[i]` 严格大于其左右相邻元素之和**（数组端点处缺失的一侧邻居按 `0` 计），则称该下标为「占优」。请返回占优下标的个数。

## 示例

### 示例 1

输入：[2, 5, 1, 6]  
输出：2  
解释：  
- 下标 1：`5 > 2 + 1` 成立
- 下标 3：`6 > 1 + 0` 成立

### 示例 2

输入：[0]  
输出：0  
解释：唯一元素 `0 > 0 + 0` 不成立，无占优下标。  

### 示例 3

输入：[-1, 2, -1]  
输出：1  
解释：下标 1：`2 > (-1) + (-1) = -2` 成立。  

## 约束

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
