# 限定频窗最长子串

给你一个仅由小写英文字母组成的字符串 `s` 和一个正整数 `k`。

如果一个子串里**每一种**字符的出现次数都不超过 `k`，则称该子串为合规子串。返回 `s` 中最长合规子串的长度。`s` 为空时返回 `0`。

实现 `longestKValidSubstring(s, k)`。不要从标准输入读数据。

## 示例

**输入：** `s = "aabaa"`, `k = 2`  
**输出：** `3`  
**解释：** 子串 `"aba"`（下标 1 到 3，0 起）长度为 3，其中 `a`、`b` 各出现 1 次，均不超过 2。更长的子串里 `a` 会出现超过 2 次。

**输入：** `s = "abcabcbb"`, `k = 1`  
**输出：** `3`  
**解释：** `"abc"` 中每种字符恰好 1 次。

**输入：** `s = "abcabcbb"`, `k = 2`  
**输出：** `6`  
**解释：** `"abcabc"` 中 `a`、`b`、`c` 各 2 次。再并入后面的 `'b'` 会使 `b` 超过 2 次。

## 约束

- `0 <= s.length <= 10^5`
- `s` 仅含小写英文字母
- `1 <= k <= 10^5`
