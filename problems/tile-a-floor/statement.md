# 铺砖方案数

## 题意

有一行地板共 $n$ 格。有三种规格的地砖可用：
- 长度 $1$ 的砖有 $a$ 种可选
- 长度 $2$ 的砖有 $b$ 种
- 长度 $3$ 的砖有 $c$ 种

若某种类别的数量为 $0$，则表示该长度的地砖不可使用。每种地砖均可无限次重复使用。求将 $n$ 格地板**恰好完全铺满**的方案总数。

设 $f(m)$ 表示铺满 $m$ 格地板的方案数，其递推关系为：
- $f(0) = 1$
- 当 $m < 0$ 时，$f(m) = 0$
- 对于 $m > 0$，$f(m) = a \cdot f(m-1) + b \cdot f(m-2) + c \cdot f(m-3)$

由于答案可能极大，请返回对 $1\,000\,000\,007$ 取模后的结果。

> **提示**：本题参数规模较大，朴素线性递推会导致超时，建议使用矩阵快速幂等 $O(\log n)$ 算法求解。中间乘积可能超出 32 位整数范围，编程时请注意使用 64 位整数或按模乘法避免溢出。

## 参数与返回值

| 参数 | 含义 | 类型 |
|---|---|---|
| `n` | 地板总格数 | `int` |
| `a` | 长度 $1$ 地砖的可选种类数 | `int` |
| `b` | 长度 $2$ 地砖的可选种类数 | `int` |
| `c` | 长度 $3$ 地砖的可选种类数 | `int` |

**返回值**：`int`，铺满方案数对 $10^9+7$ 取模的结果。

## 示例

**示例 1**
```text
输入: n = 1, a = 1, b = 1, c = 1
输出: 1
解释: 仅 1 格，只能铺 1 块长度 1 的砖，共 $a=1$ 种选法。
```

**示例 2**
```text
输入: n = 2, a = 1, b = 1, c = 1
输出: 2
解释: 可铺「长度1+长度1」或「长度2」，方案数 $f(2) = 1\times1 + 1\times1 = 2$。
```

**示例 3**
```text
输入: n = 3, a = 2, b = 3, c = 4
输出: 24
解释: $f(0)=1, f(1)=2, f(2)=2\times2+3\times1=7, f(3)=2\times7+3\times2+4\times1=24$。
```

## 约束条件

- $1 \le n \le 10^9$
- $0 \le a, b, c \le 10^9$
- 返回结果在 $[0, 10^9+6]$ 范围内。
