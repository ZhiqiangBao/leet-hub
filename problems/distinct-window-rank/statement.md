# 最多不同元素窗口数达标线

给你一个整数数组 `nums`、窗口长度 `k` 和一个正整数 `m`。

将 `nums` 上长度为 `k` 的连续子数组称为一个**窗口**。共有 `n - k + 1` 个窗口（`n` 为 `nums` 的长度）。

每个窗口包含若干个元素，其**不同元素个数**为该窗口内互不相同的元素值的种类数。

定义函数 `f(x)`：在所有窗口中，不同元素个数 **≥ x** 的窗口总数。`f(x)` 随 `x` 增大而不增（即非递增）。

你的任务是：求出使 `f(x) ≥ m` 成立的**最大**正整数 `x`。如果不存在这样的正整数（即 `f(1) < m`），返回 `0`。

## 示例

### 示例 1

输入：[1, 2, 1, 3, 2], 3, 3  
输出：2  
解释：长度为 3 的窗口共有 3 个：  

| 窗口起止下标 | 窗口内容 | 不同元素个数 |
|---|---|---|
| [0, 2] | [1, 2, 1] | 2（{1, 2}） |
| [1, 3] | [2, 1, 3] | 3（{1, 2, 3}） |
| [2, 4] | [1, 3, 2] | 3（{1, 2, 3}） |

各 `x` 值对应的 `f(x)`：
- x = 1：3 个窗口的不同元素个数均 ≥ 1 → f(1) = 3 ≥ m = 3，满足。
- x = 2：3 个窗口的不同元素个数均 ≥ 2 → f(2) = 3 ≥ m = 3，满足。
- x = 3：仅 2 个窗口（下标 [1,3] 和 [2,4]）的不同元素个数 ≥ 3 → f(3) = 2 < m = 3，不满足。

故满足条件的最大 x 为 2。

### 示例 2

输入：[1, 2, 3, 4], 2, 10  
输出：0  
解释：长度为 2 的窗口共有 3 个，每个窗口的不同元素个数均为 2：  

| 窗口起止下标 | 窗口内容 | 不同元素个数 |
|---|---|---|
| [0, 1] | [1, 2] | 2 |
| [1, 2] | [2, 3] | 2 |
| [2, 3] | [3, 4] | 2 |

f(1) = 3 < m = 10，不存在使 f(x) ≥ m 的正整数 x，返回 0。

### 示例 3

输入：[7, 7, 7, 7, 7], 1, 5  
输出：1  
解释：长度为 1 的窗口共有 5 个，每个窗口只含一个元素：  

| 窗口起止下标 | 窗口内容 | 不同元素个数 |
|---|---|---|
| [0, 0] | [7] | 1 |
| [1, 1] | [7] | 1 |
| [2, 2] | [7] | 1 |
| [3, 3] | [7] | 1 |
| [4, 4] | [7] | 1 |

f(1) = 5 ≥ m = 5，满足。x = 2 时无任何窗口满足不同元素个数 ≥ 2，f(2) = 0 < 5。故答案为 1。

## 约束

- `n == nums.length`，`1 ≤ n ≤ 10^5`
- `-10^9 ≤ nums[i] ≤ 10^9`
- `1 ≤ k ≤ n（即 1 ≤ k ≤ nums.length，窗口长度不超过数组长度）`
- `1 ≤ m ≤ 10^9`
