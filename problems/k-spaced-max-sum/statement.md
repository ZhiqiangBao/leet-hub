# 间距不小于 K 的子集最大和

给定 $n$ 个互不相同的正整数和一个正整数 $k$。请从这些数中选出若干个数构成子集，使得子集中**任意两个数的差值都不小于 $k$**（即对于子集中任意不同的数 $x, y \in a$，均有 $|x - y| \geq k$）。在所有满足该条件的子集中，求元素总和的最大值。

形式化地说：设输入数组为 $a$，从中选取下标集合 $S \subseteq \{0, 1, \dots, n-1\}$，使得对所有不同的 $i, j \in S$ 都有 $|a[i] - a[j]| \geq k$。最大化 $\sum_{i \in S} a[i]$。

## 输入格式

- 一个长度为 $n$ 的整数数组 `a`，包含 $n$ 个互不相同的正整数。
- 一个正整数 `k`。

## 输出格式

返回满足条件的子集所能达到的最大元素总和。

## 示例

**示例 1**

```
输入：a = [5, 1, 3, 8, 2], k = 3
输出：15
解释：选择子集 {2, 5, 8}：
- |2 - 5| = 3 >= 3 ✓
- |2 - 8| = 6 >= 3 ✓
- |5 - 8| = 3 >= 3 ✓
总和 2 + 5 + 8 = 15，这是所有合法子集中的最大值。
```

**示例 2**

```
输入：a = [10, 20], k = 100
输出：20
解释：|10 - 20| = 10 < 100，两数冲突不能同时选。只能二选一，最大值为 max(10, 20) = 20。
```

**示例 3**

```
输入：a = [1, 4, 7, 10, 13], k = 3
输出：35
解释：排序后为 [1, 4, 7, 10, 13]，相邻差值恰好为 3。全选满足条件：
1 + 4 + 7 + 10 + 13 = 35。
```

## 约束

- $1 \leq n \leq 10^4$（由元素互不相同且值域推导得出）
- $1 \leq a[i] \leq 10^4$，且所有元素互不相同
- $1 \leq k \leq 10^4$
