# 按题型的边界与临界

先读本题 `statement.md` 约束，只采用**约束允许**的行。下表是检查清单，不是每题都要全部类型。

## 数组 `List[int]`

| 意图 | 典型构造 |
| --- | --- |
| 下界长度 | `n` 取约束最小 |
| 上界长度 | `n` 取约束最大；解放在末尾，避免 `O(n²)` 碰巧很快 |
| 值域端点 | 出现 `min` 与 `max`（如 `-1e9`、`1e9`） |
| 临界下标 | 下标 `0` 与 `n-1` 配对；仅 `n-2` 与 `n-1` |
| 重复 | 两个相同值必须用两个下标；三个相同值时不能复用同一格 |
| 有序错觉 | 无序打乱，避免只对排序数组正确的解 |
| 全正 / 全负 / 含零 | 各至少一条（若值域允许） |

## 字符串 / `List[str]`

| 意图 | 典型构造 |
| --- | --- |
| 空串 | 仅当约束 `length >= 0` 或显式允许 |
| 单字符 | 下界 |
| 最大长度 | 上界；重复字符 vs 无公共前缀 |
| 大小写 | 仅当题面区分大小写 |
| 括号类 | 空、单对、嵌套、交错错误、前缀合法但整体不合法、只开不开 |
| 前缀 | 无公共前缀、公共前缀为整串、其中一串是另一串前缀 |

不要用含 `\u0000` 的串。不要依赖 Unicode 规范化差异，除非题面规定。

## 数值目标 `target` / 阈值 `k`

| 意图 | 典型构造 |
| --- | --- |
| 目标为 0 | 配对相反数或双零 |
| 目标为值域端点 | `min+min`、`max+max`（若仍唯一合法） |
| 刚好命中 / 差 1 | 等于 `k` 与 `k-1`（若题意是阈值） |

## 布尔返回

真、假都要有隐藏测例。不要公开全是 `true`、隐藏才出现 `false`。

## 返回数组 / 下标

- 题面「顺序任意」→ `compare: any_order`
- 题面「按原顺序 / 字典序」→ `exact`，并在隐藏测例里放会排错序的输入
- 空数组返回：仅当题意允许（两数之和通常不允许无解）

## 复杂度打击

正确解应为题面暗示的复杂度（哈希 O(n)、栈 O(n) 等）。隐藏集至少一条：

- `n` 接近最大
- 最坏布局（配对在最后、括号深深嵌套、前缀几乎全相等只在最后不同）

参考解在本机跑这条应远小于 `time_limit_ms`。若参考解都紧贴时限，缩小数据或放宽时限。

## 不要写的测例

- 超出约束
- 违反题面保证（两数之和写无解、写两个答案）
- 与公开示例相同的隐藏行
- 期望值手算且未用参考解核对
- 仅差一个无关数字的复制行（不算新覆盖）
