# 生成隐藏测例

`tests` 只写 `.qwen/tmp/<slug>_gen.py`，运行后看 `dump()` 一行摘要。口径数字与 R3 相同；本题约束以 `statement.md` 为准。

```powershell
python ".qwen/tmp/<slug>_gen.py"
```

`from emit import dump`。gen.py **只构造 `args`**（从题面想边界和错解），不要读 `ref.py`、不要自己算 `expected`。`dump` 在进程里调用磁盘上的 `solve` 填答案并打印一行摘要。禁止 `print` 测例正文。

## 上下文经济（先守这条）

模型窗口里只应出现：题面、签名、本 skill、一份短 `gen.py`、一行摘要 JSON。不要把参考解读进窗口：造输入不需要算法，填答案是 `dump` 的事。

| 做 | 不做 |
|---|---|
| `[0]*n`、`"a"*n`、`list(range(n))`、`[lo + i % k for i in range(n)]`、`random.seed(1)` 后推导 | 在 gen.py / `python -c` / 对话里写出 n≥80 的 list 或长串字面量 |
| `write_file` 只写 gen.py；shell 只跑该文件 | `read_file` / `type` / `cat` / `Get-Content` `tests.jsonl` |
| 自查 = 摘要里的 `public`、`hidden`、`hidden_n` | 把 `solve([巨大数组])` 打进命令行；打印 `rows`/`args` |
| 顶满上限 1～2 条，在脚本里构造 | 为「覆盖规模」堆很多条 `n=10^5`（搬运贵、打错解差） |

`n=5000` 的 JSON 已经接近一窗；`n=10^5` 再读回上下文会到六位数 token。磁盘可以大，**工具返回值和模型输出不能大**。

字面量上限：list 元素或字符串字符 ≤ 80。公开示例本来就短，可以写字面量。

## 条数与规模

| 类 | 条数 | 内容 |
|---|---|---|
| `hidden: false` | 2～3 | 与题面示例逐条一致 |
| `hidden: true` | ≥ 20 | 边界、临界、错解、规模 |

题面长度（或要读完的数组/串）上限 ≥ 5000 时，**隐藏**大致：

- 3～4 条：约束最小 `n`（空 / 1 / 2）和「必须很小才能表达」的临界
- 其余：`n` 取 100、200、500、1000、2000、5000 等，**不要**十几条都 `<100`
- 1～2 条：`n` = 题面上限（常见 `10^5`）
- 禁止：长度为 `10^9` 的数组。单个整数参数才可以是 `10^9`

指数 / `n!` 题：全体 ≤ 题面上限，1～2 条取上限。

`dump` 的 `hidden_n`：`lt100`、`m100_5000`、`eq_1e5`、`eq_1e9`、`at_max`。上限 ≥ 5000 而 `lt100` 占一半以上 → 改 gen.py。U 不是 `10^5` 时顶界进 `other` 正常，看 `at_max`。

答案与 `args` 内整数按签名通道：`int` 须 int32；仅 yaml `long` 可到 int64。**大多数题是 int32**。对计数题，若签名仍是 `int`，`n=10^5` 时 `n*(n-1)/2` 可能溢出，顶满条要让答案仍落在 int32（例如几乎没有合法对）。签名已是 `long` 则允许大答案，不要报 int32。

## gen.py 骨架

```python
from pathlib import Path
import sys

ROOT = Path(__file__).resolve().parents[2]
sys.path.insert(0, str(ROOT / ".qwen" / "skills" / "gen-tests"))
from emit import dump

SLUG = "the-slug"

def R(args, hidden: bool) -> dict:
    return {"args": args, "hidden": hidden}

rows = [
    R([<示例1>], False),
    R([<示例2>], False),
    R([<示例3>], False),
    # 隐藏：小 n 字面量；中大 n 只用 * / range / 推导
    R([[0] * 100], True),
    R(["ab" * 500], True),
    R([list(range(10**5))], True),
]
dump(SLUG, rows, ROOT)
```

一条一个意图。隐藏行不要复制示例。

## 通用手法（先按题面，再按 tag）

所有题先覆盖：

- 约束最小 / 最大规模（最大用脚本构造）
- 值域端点放在 **n=100～5000** 的数组上，不要另造长度 1e9
- 全相同、已排序、逆序（类型允许时）
- 解在下标 0、中间、`n-1`
- 零、负、正（数值题）
- 重复值（题意涉及时）
- 空结果 / `false`（题意允许时）
- 常见错解一条（见分 tag）

`compare: exact` 时返回必须唯一；多解用 `any_order` 或改题面指定「最小下标」等。

## 按知识点

只做本题 `tags` 相关的块。链表 / 树评测未支持，不要造节点数据。

### array

- 最小长度；全 0；`[10**9]*n`、`[-(10**9)]*n`（n 用乘法）
- 单调增 `list(range(n))`、单调减 `list(range(n, 0, -1))`
- 答案只在左端 / 只在右端：`[目标] + [无关]*(n-1)` 与反过来
- 打「只看相邻」：间隔才合法的一对，中间塞合法干扰

### hash

- 缺失键（应走默认分支）
- 大量重复：`[x]*n` 与「除一个外全相同」
- 无序：不要用已排序数组当唯一隐藏数据（排序冒充哈希）
- 两数之和类：配对放在最后，打掉提前 break 的 O(n²)

### string

- 空串（约束允许）；单字符；`"a"*n`；`"a"*(n-1)+"b"`（前缀陷阱）
- 字符集边界：全 `z`、交替 `"ab"* (n//2)`
- 不要 `\0`、不要靠 Unicode 正规化
- 括号类：只开、只闭、前缀合法整体不合法、最深嵌套用 `"("*k+")"*k` 在脚本里拼

### stack

- 空、单对、交错错误
- 长前缀合法、最后一格才坏：`"("*1000 + ")"*999 + "("` 这类用乘法拼
- 打「只计数量不计顺序」：`][` 与 `[]` 条数相同顺序不同

### two-pointers

- 已排序 *和* 逆序 *和* 乱序（`seed` 打乱）各至少一条中等 n
- 答案在两端相遇 / 在相邻两格
- 打「一头固定」：左端无解、右端才有

### sliding-window

- `k=1`、`k` 大到窗口可吃整串、`k` 刚好卡在收缩点
- 全相同字符；窗口在最后一格才超标：`"a"*(n-1)+"b"` 配小 k
- 打「最多 k 种字符」误当成「每种次数 ≤k」或反过来——用题面定义造反例
- 中等 n 用 `"abc"*(n//3)`，不要手写三千个字符

### binary-search

- 找不到；答案在 0 / `n-1` / 中点
- 单调性边界：`false` 前缀转 `true` 的第一格
- 有重复时题面必须规定返回哪一个，否则不要 `exact`
- 大 n：`list(range(n))` 或两段常数拼接，不要枚举 1e5 个字面量

### greedy

- 局部最优 ≠ 全局：短的反例可用字面量，再在 n=100～5000 上放大同一模式（周期重复）
- 已排序输入会让错贪心碰巧对——必须有乱序中等 n

### dp

- `n=1`、转移式第一项 / 模数边界
- 某一转移系数为 0（如铺砖只有长度为 2 的砖）
- `n` 为 `10^9` 时只改**那个整数**，用矩阵/公式参考解；禁止展开成长数组
- 小 n 可用递推手核 gen.py，大 n 仍 `solve(...)`

### math

- 0、1、`-1`、值域端点 `±10^9`（这是值，不是长度）
- 溢出：中间乘积用 64 位才对的数据；答案按签名通道进 int32 或 int64，或按题面取模。不要无故把 int 题做成 long。

### sorting

- 已有序、逆序、全相同（排序无操作）
- 稳定性若题面未保证，不要用 `exact` 卡相对顺序

## 顶满规模怎么写（省 token）

```python
n = 10**5
R([[0] * n], True)
R([list(range(n))], True)
R(["z" * n, 1], True)
R([n, 10**9, 0, 0], True)  # 整数 n，不是长度为 n 的数组
```

最坏布局也用拼接：`[1] * (n-2) + [目标, 目标]`，不要列出 n 个数。

## 不要写

- 越题面约束
- 违反保证（保证唯一解却造多解）
- 隐藏行复制示例
- 手算大样例的 `expected`
- 只改一个无关数字的重复行
- 链表/树结构（评测无这些类型）
