# R1 · 选题

**读的人**：`author`、`quality`。

## 原创

- 不出力扣能对上号的原题（两数之和、有效括号、最长公共前缀、买卖股票、爬楼梯、岛屿数量、股票跨度、极差窗口 max−min≤k、最少翻转/反转使括号合法、最短连续子数组 gcd=1、组合数 nCr 取模、错排 derangement、子串贡献和等），也不许只换故事或变量名。能立刻想起力扣编号或 GFG 标题的不要出。
- 允许考同一类算法（哈希、栈、双指针、二分、滑动窗口、贪心、排序），题意、保证、返回值须另立。
- 库内不要与 `problems/catalog.md` 已有行撞同一保证+返回值。只读题表，不要扫其它 `problems/<slug>/`。
- slug 未占用（以题表为准）；只含小写字母、数字、连字符；目录名等于 slug。

## 难度与知识点

- `difficulty`：`easy` / `medium` / `hard`。一批须难易搭配。
- `tags` 只用：`array`、`hash`、`string`、`stack`、`two-pointers`、`sliding-window`、`binary-search`、`linked-list`、`tree`、`greedy`、`dp`、`math`、`sorting`。每题 1～3 个。
- 参数或返回值不要用链表、二叉树（评测未支持）。

## 规模

本题面里的 **`n` 只表示输入规模**，不是元素上写的数字。

| 写法 | 含义 | 不是 |
|---|---|---|
| `n = nums.length` 或 `n = s.length` | 数组或字符串有多长，循环跑几圈 | 不是 `nums[i]` 的大小 |
| `n` 为单个整数参数 | 这个整数有多大 | 不是要开长度为 n 的数组 |
| 指数 / 排列题的 `n` | 要展开的个数（子集 2^n、排列 n!） | 不是值域 |

**值域**另写：`nums[i]`、`target` 等，力扣多数是 `±10^9`。默认走 R4 的 `int`（int32）。只有答案或参数会超 \(2^{31}-1\) 时才用 `long`。值可以是 `10^9`，**数组长度不能是 `10^9`**。

题面 `n` 上限按正确解复杂度取：

| 正确解 | `n` 是什么 | 上限 |
|---|---|---|
| O(n) / O(n log n)，要读完整段输入 | 长度 | `10^5`（偶用 `10^4`）。O(n²) 在此 TLE |
| O(log n) / O(1) / 数位，不开长数组 | 那个整数 | `10^9` |
| O(2^n) | 个数 | 15～20 |
| O(n!) 或排列展开 | 个数 | 8～12 |

测例如何取长度见 R3。约束分别写清：`n`（规模）、值域、字符集、解是否唯一、元素是否可复用。

- C：自由函数，无 `class Solution`。
- 不从标准输入读数据。
