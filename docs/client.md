# 客户端操作

客户端是打开评测网页的设备：Windows、macOS、手机，或 Ubuntu 本机浏览器。客户端不安装 Python / gcc / g++，也不保存账号。账号、题库和判题都在 Ubuntu 评测主机上。

服务端部署与启停见 [server.md](server.md)。

## 打开网站

浏览器访问：

```text
http://<Ubuntu局域网IP>:8080
```

IP 由评测主机执行 `hostname -I` 得到。必须带端口 `8080`。

若地址是 `http://127.0.0.1:8080` 或 `localhost:5173`，则连的是本机开发服务，不是家里那台 Ubuntu（除非你人就在 Ubuntu 上访问本机）。

## 注册与登录

用户名：3–32 个字符，字母、数字、下划线。密码至少 4 位。

评测主机上还没有任何用户时，第一个成功注册的账号是管理员，登录后顶栏出现「管理」。之后注册的账号是普通用户。

同一用户名可在任意客户端登录，都是评测主机上的同一个账号。

## 做题

1. 登录后进入题目列表。状态：已通过为 `AC`，做过未通过为 `—`。
2. 打开题目：左侧题面，右侧编辑器。
3. 语言下拉框中，可评测的语言可选；未安装编译器或未实现适配器的语言为灰色（提交为 `NA`）。当前可评测的是 Python 3、C、C++20（视评测主机是否装有 `python3` / `gcc` / `g++`）。
4. 按 starter 补全函数：Python / C++ 是 `class Solution` 的方法；C 是力扣式自由函数。不要自行编写 `main`（C / C++）。
5. 提交后页面轮询结果。

判定：

| 结果 | 含义 |
| --- | --- |
| `AC` | 全部测例通过 |
| `WA` | 答案错误 |
| `TLE` | 超时 |
| `MLE` | 超出内存 |
| `RE` | 运行时错误 |
| `CE` | 编译失败 |
| `NA` | 语言不可用 |

公开测例失败时显示输入、期望与输出。隐藏测例只显示序号。

「提交记录」页列出当前登录用户自己的历史。

## 管理员（网页）

顶栏有「管理」时，可创建题目、替换或追加测试集、从磁盘重载题库。这些操作写入**评测主机**的 `problems/`，不是客户端本地磁盘。

日常出题仍应改仓库并推送 GitHub，见 [problems.md](problems.md)。网页管理适合临时改一题。

## 接口文档

```text
http://<Ubuntu局域网IP>:8080/docs
```

供查看 API，不是做题页。
